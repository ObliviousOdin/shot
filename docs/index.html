Screenshots that paste into the right thing.

A lightweight take on Screenshot for Chat. Capture a region. The image goes to visual apps. The temp path goes to your coding agent.

curl -fsSL https://obliviousodin.github.io/shot/install.sh | sh

Drops ~/.local/bin/shot. macOS and Linux. No compiler, no cask.

CLI

Same idea as a 6 KB script.

  • $ shotregion
  • $ shot -wwindow
  • $ shot -ffull screen
# writes  $TMPDIR/shot-YYYYMMDD-HHMMSS.png
# copies  PNG  →  visual apps
# copies  path →  terminals / agents
# prints  the path on stdout

How it works

01

Capture

Region, window, or full screen. One shell command on your machine.

02

Dual clipboard

PNG and temp path written together. Apps pick the format they want.

03

Paste into chat

Slack gets pixels. Claude Code gets /tmp/shot-….png. No extra hop.

Versus the original

Same paste. Smaller surface.
